Website Ucapan Terima Kasih untuk Guru SMK 🎓

Website sederhana, elegan, dan bermakna yang didedikasikan untuk seluruh Bapak dan Ibu Guru di SMK. Proyek ini dirancang dalam satu file agar sangat mudah dibagikan dan langsung bisa di-online-kan menggunakan GitHub Pages.

✨ Fitur Utama

Desain Minimalis & Profesional: Nyaman dibaca dengan tipografi yang rapi, cocok dibuka lewat HP maupun laptop.

Interaktif: Dilengkapi tombol khusus untuk menampilkan pesan dan doa tambahan.

Single-File (index.html): Tidak memerlukan konfigurasi rumit, tanpa folder aset tambahan (CSS dan JS sudah disatukan).

🚀 Cara Menggunakan & Upload ke GitHub

Ikuti langkah-langkah mudah berikut untuk meng-online-kan website ini:

Buat Repository Baru:

Masuk ke akun GitHub kamu.

Klik tombol New (atau ikon + di pojok kanan atas).

Beri nama repository (contoh: ucapan-untuk-guru).

Pilih visibilitas menjadi Public.

Jangan centang opsi Add a README file (karena kita sudah punya filenya sendiri).

Klik Create repository.

Upload File:

Di halaman repository baru kamu, klik tulisan uploading an existing file.

Seret (drag & drop) atau pilih file index.html dan README.md ke halaman tersebut.

Ketik pesan commit di bagian bawah (misal: "Upload website ucapan guru") lalu klik tombol hijau Commit changes.

Aktifkan GitHub Pages:

Masuk ke tab Settings di bagian atas repository kamu.

Di menu sebelah kiri, cari dan klik bagian Pages.

Pada bagian Build and deployment > Branch, ubah dari None menjadi main (pastikan folder tetap di / (root)).

Klik tombol Save.

Selesai!

Tunggu sekitar 1–2 menit, lalu refresh halaman Settings > Pages tersebut.

Link website kamu akan muncul di bagian atas (contoh: https://username-kamu.github.io/ucapan-untuk-guru/).

Salin link tersebut dan bagikan ke grup WhatsApp guru atau sosial media!

🛠️ Cara Menyesuaikan Konten (Opsional)

Jika kamu ingin mengubah nama sekolah, jurusan, atau isi pesannya, buka file index.html menggunakan aplikasi teks editor seperti Notepad, VS Code, atau Notepad++, lalu ubah teks sesuai keinginan sebelum mengunggahnya ke GitHub.
